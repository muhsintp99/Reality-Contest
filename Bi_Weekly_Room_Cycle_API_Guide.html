Part 2: Admin Room Cycle Management APIs (27 Endpoints)

All admin endpoints are routed through /api/admin/room-cycle/...:

  • Rooms: GET /api/admin/room-cycle/rooms, POST /api/admin/room-cycle/rooms, GET /api/admin/room-cycle/rooms/:id, PUT /api/admin/room-cycle/rooms/:id, DELETE /api/admin/room-cycle/rooms/:id, GET /api/admin/room-cycle/rooms/:id/cycles, POST /api/admin/room-cycle/rooms/bulk-action
  • Members: POST /api/admin/room-cycle/members/assign, POST /api/admin/room-cycle/members/random-assign, POST /api/admin/room-cycle/members/transfer, DELETE /api/admin/room-cycle/members/:roomId/:userId
  • Cycles: GET /api/admin/room-cycle/cycles, POST /api/admin/room-cycle/cycles, PUT /api/admin/room-cycle/cycles/:id/set-active, GET /api/admin/room-cycle/cycles/:id, PUT /api/admin/room-cycle/cycles/:id, DELETE /api/admin/room-cycle/cycles/:id
  • Submissions & Grading: GET /api/admin/room-cycle/submissions, PUT /api/admin/room-cycle/submissions/:id/review
  • Leaderboard & Scores: GET /api/admin/room-cycle/leaderboard, POST /api/admin/room-cycle/leaderboard/recalculate
  • Rewards Distribution: GET /api/admin/room-cycle/rewards, POST /api/admin/room-cycle/rewards, POST /api/admin/room-cycle/rewards/distribute
  • Settings & Analytics: GET /api/admin/room-cycle/settings, PUT /api/admin/room-cycle/settings, GET /api/admin/room-cycle/analytics
MODULE B: Grand Contest Module
Part 1: Contestant & Mobile App Grand Contest APIs

Step 1: List Grand Contests

GET /api/grand-contests (or /api/public/grand-contests)

{
  "success": true,
  "data": {
    "contests": [
      {
        "_id": "66bc91f24d9e123456789gnc1",
        "contestId": "GNC-2026-98124",
        "title": "Grand Championship Season 1",
        "prizePool": 100000,
        "entryFee": 499,
        "entryFeeType": "Cash",
        "tasksCount": 5,
        "status": "Registration Open"
      }
    ]
  }
}

Step 2: Get Details & Rules

GET /api/grand-contests/:id

{
  "success": true,
  "data": {
    "_id": "66bc91f24d9e123456789gnc1",
    "title": "Grand Championship Season 1",
    "rules": "1. Complete all assigned task challenges before deadline.",
    "tasks": ["66bc91f24d9e987654321task1"]
  }
}

Step 3: Join Grand Contest

POST /api/grand-contests/:id/join (or /api/v1/mobile/grand-contests/:id/join)

{
  "success": true,
  "message": "Joined Grand Contest successfully",
  "data": { "contestId": "66bc91f24d9e123456789gnc1", "status": "Registered" }
}

Step 4: Fetch Tasks & Submit Proof

GET /api/grand-contests/:id/tasks

POST /api/grand-contests/:id/tasks/:taskId/submit (or /api/grand-contests/:id/submissions)

// Request Body:
{
  "submissionType": "Video",
  "mediaUrl": "/uploads/submission/video_1723630000.mp4",
  "proofNotes": "Here is my 30-second strategy pitch video."
}

Step 5: View Submissions & Analytics

GET /api/grand-contests/:id/submissions

GET /api/grand-contests/:id/analytics

  • Contest CRUD: POST /api/admin/grand-contests, GET /api/admin/grand-contests, GET /api/admin/grand-contests/:id, PUT /api/admin/grand-contests/:id, DELETE /api/admin/grand-contests/:id, POST /api/admin/grand-contests/:id/duplicate
