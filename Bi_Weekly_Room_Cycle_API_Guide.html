📱 Bi-Weekly Room Cycle & Grand Contest Modules API Guide

Version 2.0.0 Target: iOS & Android Mobile App Base Server: http://hakalive.in/api/v1

1. Global Authentication Header (Required for All Requests)

Authorization: Bearer <user_jwt_access_token>
Content-Type: application/json
MODULE A: Bi-Weekly Room Cycle Module

Step 1: Browse Available Rooms

GET /api/v1/week/rooms

{
  "success": true,
  "data": {
    "rooms": [
      {
        "_id": "66bc91f24d9e123456789rm1",
        "code": "RM-001",
        "name": "Alpha Strikers",
        "maxMembers": 50,
        "membersCount": 12,
        "isJoined": false,
        "status": "Active"
      }
    ]
  }
}

Step 2: Room Details & 14-Day Cycle Blueprint

GET /api/v1/week/rooms/:id | GET /api/v1/week/rooms/:id/cycles

{
  "success": true,
  "cycles": [
    {
      "_id": "66bc91f24d9e123456789cyc1",
      "cycleNumber": 1,
      "title": "Bi-Weekly Sprint 1",
      "durationDays": 14,
      "prizePoolCoins": 5000,
      "status": "Active"
    }
  ]
}

Step 3: Check Eligibility & Join Room Cycle

GET /api/v1/week/rooms/:roomId/contests/:contestId/check-status

POST /api/v1/week/rooms/:roomId/contests/:contestId/join

{
  "success": true,
  "message": "Successfully joined room cycle",
  "data": { "roomId": "66bc91f24d9e123456789rm1", "status": "Active" }
}

Step 4: Submissions, Leaderboard & Rewards

GET /api/v1/admin/room-cycle/submissions?roomId=<roomId>

GET /api/v1/admin/room-cycle/leaderboard?roomId=<roomId>

GET /api/v1/admin/room-cycle/rewards

MODULE B: Grand Contest Module

Step 1: List Grand Contests

GET /api/v1/grand-contests

{
  "success": true,
  "data": {
    "contests": [
      {
        "_id": "66bc91f24d9e123456789gnc1",
        "contestId": "GNC-2026-98124",
        "title": "Grand Championship Season 1",
        "prizePool": 100000,
        "entryFee": 499,
        "entryFeeType": "Cash",
        "tasksCount": 5,
        "status": "Registration Open"
      }
    ]
  }
}

Step 2: Get Details & Rules

GET /api/v1/grand-contests/:id

{
  "success": true,
  "data": {
    "_id": "66bc91f24d9e123456789gnc1",
    "title": "Grand Championship Season 1",
    "rules": "1. Complete all assigned task challenges before deadline.",
    "tasks": ["66bc91f24d9e987654321task1"]
  }
}

Step 3: Join Grand Contest

POST /api/v1/grand-contests/:id/join

{
  "success": true,
  "message": "Joined Grand Contest successfully",
  "data": { "contestId": "66bc91f24d9e123456789gnc1", "status": "Registered" }
}

Step 4: Fetch Connected Tasks & Submit Proof

GET /api/v1/grand-contests/:id/tasks

POST /api/v1/grand-contests/:id/tasks/:taskId/submit

// Request Body:
{
  "submissionType": "Video",
  "mediaUrl": "/uploads/submission/video_1723630000.mp4",
  "proofNotes": "Here is my 30-second strategy pitch video."
}

Step 5: View Submissions & Analytics

GET /api/v1/grand-contests/:id/submissions

GET /api/v1/grand-contests/:id/analytics
